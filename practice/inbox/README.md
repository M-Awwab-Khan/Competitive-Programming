# Solution inbox

Drop new `.cpp` or `.py` attempts here. From the repository root, preview with `python3 scripts/ingest.py`, then file them with `python3 scripts/ingest.py --apply`.

The organizer also detects non-legacy sources elsewhere in `practice/` and stray root-level sources. Classification is suggested from local code/title signals. You can ask the repository agent to read and review new attempts using the workflow in `AGENTS.md`.
