# Practice workspace

Put new attempts in [inbox/](inbox/). Preview with `python3 scripts/ingest.py` from the repository root; apply with `--apply`, or ask the agent to organize new solutions.

Source files remain visible to Git; root-level text input/output files in this folder are ignored. The runner uses this directory for relative file I/O. Existing experiments in `legacy/` are preserved and excluded from automatic ingestion.
